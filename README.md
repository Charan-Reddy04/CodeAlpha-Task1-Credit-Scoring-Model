# Credit Scoring Model

A Machine Learning based Credit Scoring Model developed as part of the CodeAlpha Machine Learning Internship.

## Project Objective

The objective of this project is to predict an individual's creditworthiness using historical financial and credit-related information.

The model classifies an applicant into:

- Good Credit
- Bad Credit
